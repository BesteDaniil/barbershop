# Изображения

Сайт использует фото напрямую с **Unsplash** (CDN), поэтому папка может
оставаться пустой — всё работает как есть.

## Где используются фото
- **Первый экран (hero)** — фон в `css/style.css`, селектор `.hero__bg`
  (`photo-1503951914875-452162b0f3f1`). Тёмный барбершоп.
- **Мастера** — 3 портрета в `index.html`, теги `.master__photo img`.

## Как заменить на свои
1. Положите файлы сюда: `images/hero.jpg`, `images/master-1.jpg` и т.д.
2. Замените ссылки на **относительные пути** (без ведущего слэша):
   - в CSS (из папки `css/`): `url('../images/hero.jpg')`
   - в HTML: `src="images/master-1.jpg"`
3. Рекомендации: hero ~1600×1000 (тёмное, контрастное), портреты ~600×750.
   Формат JPG/WebP, сжать на squoosh.app.

Фото на Unsplash — свободная лицензия.
